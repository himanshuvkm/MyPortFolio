## 📖 Description

MyPortFolio is a meticulously crafted open-source portfolio template designed for developers, designers, and creatives who want to make a lasting impression.

Built with:

- **Next.js** for blazing fast performance  
- **Tailwind CSS** for effortless styling  
- **shadcn/ui** for beautiful, accessible components  

It includes smooth animations, dark mode, a clean responsive design, and a modern project layout that looks stunning on all devices.  
Perfect for creating a personal brand that stands out.

## 🚀 Getting Started

```bash
git clone https://github.com/himanshuvkm/MyPortFolio
cd MyPortFolio
npm install
npm run dev
```

---

## 🔧 How to Customize

- Update text & sections in `app/`
- Modify theme & colors in `tailwind.config.js`
- Add your projects in `components/Projects`
- Connect the contact form using:
  - Resend  
  - Formspree  
  - EmailJS
